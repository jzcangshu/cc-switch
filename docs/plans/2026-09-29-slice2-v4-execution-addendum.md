### 2.2 五字段匹配：维护约束与误拒绝边界

基线 `src-tauri/src/live/project/codex.rs` 的真实生成函数如下；这是原始代码，不是建议新增一份拷贝：

```rust
pub fn official_mirror_table(base_url: Option<&str>, supports_websockets: bool) -> Table {
    let mut table = Table::new();
    table.insert("name", toml_edit::value("OpenAI"));
    table.insert("requires_openai_auth", toml_edit::value(true));
    table.insert("supports_websockets", toml_edit::value(supports_websockets));
    table.insert("wire_api", toml_edit::value("responses"));

    }

```

守卫精确匹配此函数的代理形态：共享选择器、五字段、官方认证开启、双向长连接关闭，以及有效的 HTTP（普通超文本传输）地址、`/v1`（版本一路径），无用户信息、查询或片段。保持严格匹配，不因未来字段可能变化而现在放宽。

必须在守卫旁标注与真实生成函数同步维护；测试调用真实生成函数，不能仅手写同样的五字段。生成函数以后新增字段时，该测试应失败，迫使开发者重新核对导入边界。

允许任意主机意味着远端同形手工配置也会被拒绝导入。这是保守的误拒绝，不是该配置归应用所有的证据。测试至少覆盖回环地址、网卡地址、第六版互联网协议地址及 `http://remote.example/v1`（远端示例地址）。禁止把域名解析、当前监听端口或网络探测加入纯配置判定。

## 4. 旧会话过渡是发布阻断条件

### 4.1 已验证的具体风险

基线写引擎的原始清理条件位于 `src-tauri/src/live/project/codex.rs` 的路由写入方法：

```rust
.filter(|(id, item)| {
    *id != ROUTE_ID
        && !referenced.iter().any(|name| name == id)
        && (*id == OFFICIAL_PROXY_ROUTE_ID
            || holds_placeholder(item)
            || self.is_retired(id, item))
})
```

因此切到共享选择器时，没有配置档引用豁免的旧官方代理定义会被清理。这是既有引擎规则；不能在本切片随意删掉条件。

使用桌面内置客户端 `0.158.0-alpha.2.1`（实测版本），在同一个隔离客户端目录先运行旧代理配置，再仅替换为共享代理配置并重启服务，不重新播种历史。旧代理合成会话升级前恢复成功，升级后返回：

> failed to load configuration: Model provider `cc-switch-official` not found（配置加载失败：找不到旧官方代理供应商）。

本实验使用等价配置形态，不是端到端运行产品安装升级器。它与上述真实清理代码共同证明风险链。没有发送模型请求，没有读取真实登录凭据。

新建会话调用已实际返回旧/共享供应商标识，且对应落盘文件的会话元数据分别为旧/共享标识。不能把此证据扩展为真实消息发送、所有运行时字段或所有客户端版本均正确。该客户端读取新会话完整轮次返回“暂不支持列出轮次”，此限制单独记录，不作为落盘失败。

### 4.2 每种迁移状态的发布契约

| 迁移状态       | 必须保持的语义                             | 发布前必需证明                                           |
| -------------- | ------------------------------------------ | -------------------------------------------------------- |
| 用户未选择迁移 | 不改旧历史标签、正文或数据库；不得强制勾选 | 旧会话有可验证的恢复路径；默认列表仍可分桶，应明确说明   |
| 已选择但等待   | 不能把已保存设置说成历史已迁完             | 尚未处理的旧会话仍可恢复，等待原因可诊断                 |

## 5. 设置失败与恢复：不改事务主逻辑

基线 `src-tauri/src/commands/settings.rs` 的真实控制流节选：

```rust
let unify_codex_changed =
    merged.unify_codex_session_history != existing.unify_codex_session_history;
crate::settings::update_settings(merged).map_err(|e| e.to_string())?;
if unify_codex_changed {
    if let Err(err) =
        crate::services::provider::reapply_current_codex_official_live(state.inner())
    {
        // 原代码在此尝试写回 existing，并返回错误。
        // 后续迁移任务尚未启动。
    }
}
```

上述片段仅省略错误日志和返回构造，不能复制成补丁。存在两层状态：设置回滚与写引擎未完成操作的前向恢复。测试必须先确认错误确实来自指定“配置已发布”故障点，不能只看到错误返回就断言事务已部分发布。

需要分别验证：返回错误后设置值、活动配置、未完成操作；再次保存相同设置值；单独完成未完成操作；完整模式启动。完整模式启动会使用强制接入路径重算配置，不能根据只调用恢复函数的实验声称永久不一致。

第四版真实入口实验已确认：在配置发布后注入错误，设置回滚为关闭，但磁盘已经是共享选择器且留有未完成操作；保存同一个关闭值不会进入开关变更分支，未完成操作仍在；单独完成恢复会清除未完成操作，但仍保留共享选择器；调用完整模式启动后，强制接入按当前关闭设置恢复旧代理选择器。此结论针对实验状态及该故障点，不推断所有失败点同样表现。

此项属于独立事务一致性关切。除诊断测试外，不把改造设置保存、写引擎恢复或主启动流程混入切片二。实际测量结论与尚未抵达的断言以第四版证据说明为准。
