# 第三版界面与第四版内核融合实现计划

> 执行：采用 subagent-driven-development（子代理开发）与 code-review-and-quality（代码质量审查），按下列任务执行并独立审查。用户已授权一次完成，无需分段确认。

**目标：** 以最后正式第三版 v3.20.4 的视觉与操作路径为基准，在正式版 v4.0.18 上恢复界面；保留第四版内核、数据契约、新增能力和正确性修复。

**架构：** 第四版作为唯一运行时。复用第三版无业务副作用的组件与布局，在第四版现有业务组件上恢复呈现；不构建双内核、兼容后端或第二套业务状态。模式动作继续使用第四版的模式控制器；供应商编辑继续使用编辑投影与冲突处理；会话继续使用结构化块与分块加载。

**技术：** React（界面框架）、TypeScript（类型系统）、Tailwind（样式工具）、TanStack Query（查询缓存）、Tauri（桌面框架）、Rust（内核语言）。依赖及锁文件固定为第四版。

## 明确排除的已移除功能

- 不复活第三版的通用配置片段合并；共享设置由第四版留在客户端配置中。兼容命令存在不代表仍应展示旧入口。
- 不复活供应商成本倍率、默认倍率设置或连通性高级参数。
- 不把旧代理开关直接等同于第四版模式切换；查看模式不能触发配置写入。
- 不把会话的可选纯文本作为唯一内容源；不把技能新结果对象当作数组。
